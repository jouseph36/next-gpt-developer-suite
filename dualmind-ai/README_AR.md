# DualMind AI — تطبيق مفتوح الكود يجمع OpenAI وClaude

> **ليس** كود ChatGPT أو Claude الداخلي ولا نموذجًا مستقلاً بذاته. هذا التطبيق من كتابة مستقلة، يتصل بواجهات API الأصلية عبر مفاتيحك الشخصية.

## المزايا الفعلية في هذه النسخة

- محادثة مباشرة مع OpenAI (Responses API) أو Claude (Messages API)
- بث الكلمات تدريجيًا Streaming مع زر إيقاف
- اختيار النموذج وإمكانية تعديل أسماء النماذج من إعدادات الخادم
- وضع مقارنة يرسل السؤال إلى المزودين (قد يضاعف التكلفة)
- رفع الصور PNG/JPG/WEBP/GIF وملفات PDF (حد 3MB للملف، 3 ملفات للرسالة)
- وضع بحث ويب باستخدام أدوات API الأصلية **إذا كانت مفعّلة لحسابك**، وقد ينتج عنه رسوم إضافية
- سجل محادثات محلي على الجهاز باستخدام IndexedDB، مع بحث وحذف وتصدير واستيراد
- تصميم عربي RTL، استجابة للجوال، وضع فاتح/داكن
- كلمة مرور تطبيق اختيارية محليًا، ويشترط الخادم 20 حرفًا على الأقل في وضع الإنتاج
- مفاتيح API محفوظة على **الخادم فقط**، ولا تُرسل للواجهة
- الإملاء الصوتي من متصفحك **إن كان يدعمه**، وليس صوت ChatGPT Realtime
- لا توجد مكتبات npm؛ يعمل مع Node.js 20 أو أحدث

## طريقة التشغيل

1. ثبّت Node.js 20+ على السيرفر (أو جهازك).
2. انسخ `.env.example` إلى `.env`.
3. أدخل على الأقل مفتاح API واحدًا:

```env
OPENAI_API_KEY=your_key_here
ANTHROPIC_API_KEY=your_key_here
APP_PASSWORD=your_very_long_random_password
PORT=3000
```

4. شغل المشروع:

```bash
npm start
```

5. افتح `http://localhost:3000` أو رابط سيرفرك المحمي بـHTTPS.
6. افتح «الإعدادات والخصوصية» داخل التطبيق، وأدخل `APP_PASSWORD` الذي حددته على الخادم.

تُحتسب طلبات التطبيق على مشروع API لدى المزوّد الذي تختاره. تعرض لوحة المزوّد الرصيد المتاح وتكلفة الاستخدام.

## التشغيل من iPhone فقط باستخدام Render + GitHub

1. الخدمة المنشورة هي `dualmind-ai-jouseph` وتستخدم ملفات المجلد `dualmind-ai` على الفرع `deploy/dualmind-ai`.
2. من صفحة **Environment** في Render أضف `OPENAI_API_KEY` لتفعيل OpenAI أو `ANTHROPIC_API_KEY` لتفعيل Claude. تفعيل الاثنين يتيح المقارنة.
3. اختر **Save and deploy** وانتظر ظهور **Live**.
4. افتح التطبيق من الآيفون، ثم أدخل قيمة `APP_PASSWORD` في «الإعدادات والخصوصية».

**مهم:** خطة Render المجانية قد تكون مقيدة أو قد تتغير. تحقّق من الأسعار الحالية. على الاستضافة العامة هذا المشروع مناسب لحساب خاص أو تجربة؛ ليس منصة متعددة المستخدمين جاهزة للإنتاج.

## البنية

```

public/index.html    واجهة عربية
public/style.css     تصميم متجاوب
public/app.js        المحادثات والتخزين والمقارنة والبث
render.yaml          نموذج نشر على Render
.env.example         متغيرات البيئة
 test/providers.test.js  اختبارات أساسية
```

## الخصوصية والقيود

- المحادثات **تُحفظ في متصفحك** وتُرسل إلى OpenAI أو Anthropic لتنفيذ الاستجابة. السيرفر لا يحفظ نصوص المحادثات في قاعدة بيانات، لكنه يمررها للمزود الذي اخترته.
- تخزين المتصفح المحلي ليس تشفيرًا طرفيًا، وقد يستطيع شخص لديه وصول لجهازك/ملف المتصفح قراءتها. تصدير JSON غير مشفر.
- يتم إرسال مرفقات الرسالة الجديدة فقط إلى مزود الذكاء الاصطناعي؛ المرفقات القديمة لا يعاد إرسالها تلقائيًا في الطلبات اللاحقة، لتحجيم التكلفة وحجم الرفع.
- لا يشمل هذا المشروع صوتًا مباشرًا شبيهًا بوضع Live، ولا توليد الصور والفيديو، ولا تنفيذ أوامر على جهاز المستخدم، ولا وكلاء متعددين، ولا اتصالات بنكية أو أدوات تنفيذ كود محمية (sandbox)، ولا نظام حسابات/مزامنة عبر أجهزة، ولا بحثًا دائمًا في مكتبة ملفات.
- الصور وPDF قد لا تُقبل بواسطة جميع النماذج، وأدوات بحث الويب قد تكون غير متاحة لبعض الحسابات أو النماذج.
- يسمح الخادم باثني عشر طلب محادثة في الدقيقة لكل عنوان اتصال.
- `APP_PASSWORD` يمنع استدعاء API عبر واجهة الخادم دون كلمة المرور؛ اختيار كلمة طويلة وفريدة وHTTPS شرط أساسي.
- أحدث المعايير وأسماء النماذج قد تتغير؛ عدل `.env` حسب توثيق المزود.
