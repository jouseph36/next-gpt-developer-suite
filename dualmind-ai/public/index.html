فكّر بطريقتين.

استخدم Gemini وGroq ضمن الحصص المجانية المتاحة، أو OpenAI وClaude إذا توفر رصيد. مفاتيح API تبقى على خادمك.

توفّر الحصة المجانية يعتمد على حسابك والمنطقة وحدود المزود. عند تفعيل الفوترة قد تنطبق رسوم API.

الإعدادات والخصوصية

مفاتيح API تبقى على الخادم. المحادثات محفوظة في مساحة تخزين المتصفح (IndexedDB) وتُرسل لمزود النموذج عند الطلب.

مفاتيح مجانية: إنشاء Gemini API · إنشاء Groq API. أضف المفتاح في Render → Environment باسم GEMINI_API_KEY أو GROQ_API_KEY. الحصص المجانية ليست مضمونة لكل حساب.

⚠ لا تخزّن أرقام بطاقات أو مفاتيح سرية في المحادثات. لا تنشر السيرفر بدون APP_PASSWORD وHTTPS.
