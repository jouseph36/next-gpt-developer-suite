# Contributing

Thanks for helping improve Next GPT Developer Suite.

1. Open an issue explaining the proposed change.
2. Create a feature branch and keep pull requests focused.
3. Add or update standard-library unit tests.
4. Run `python -m unittest discover -s tests -v`.
5. Never include secrets, private data, credentials or proprietary prompts.

Changes involving external APIs should be opt-in, documented, and tested with mocks. CI must not require paid credentials.
